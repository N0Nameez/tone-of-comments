## 🌟 О проекте

Данный проект представляет собой веб-приложение для анализа комментариев, которое определяет:
1. **Токсичность** — Вероятность того, что комментарий содержит оскорбления, угрозы или негативный контент (модель CNN). Точность: 0.8848.
2. **Тональность** — Эмоциональная окраска текста: позитивная, негативная или нейтральная (модель RuBERT). Точность: 0.8079.

Результаты анализа сохраняются в базу данных MySQL для мониторинга и сбора статистики.

---

## ✨ Особенности

- 🔍 **Определение токсичности:** Шкала от 0 до 1 для оценки вероятности негативного контента.
- 🎯 **Классификация тональности:** Определение позитивной, негативной или нейтральной окраски текста.
- 💾 **Сохранение результатов:** Использование базы данных MySQL для хранения проанализированных данных.
- 🖥️ **Удобный интерфейс:** Веб-приложение на базе Streamlit для визуализации результатов.
- 🚀 **REST API:** Поддержка сторонних интеграций через API на FastAPI.
- 🇷🇺 **Поддержка русского языка:** Модели специально обучены на русскоязычных датасетах.

## ⚙️ Установка и запуск

**1. Клонируйте репозиторий**
```bash
git clone https://github.com/N0Nameez/tone-of-comments.git
cd tone-of-comments
```

**2. Создайте виртуальное окружение**
```bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

**3. Установите зависимости**
```bash
pip install -r requirements.txt
```

**4. Настройте базу данных**
Создайте базу данных и необходимые таблицы:
```sql
CREATE DATABASE comments_db;
USE comments_db;

CREATE TABLE comments (
    id INT AUTO_INCREMENT PRIMARY KEY,
    text TEXT NOT NULL,
    toxicity FLOAT,
    sentiment VARCHAR(50),
    created_at DATETIME
);
```
Обновите конфигурационный файл (в `api.py`), указав ваши учетные данные:
```python
DATABASE_URL = "mysql+pymysql://root:1234@localhost:3306/comments_db"
```

**5. Проверьте файлы моделей**
Убедитесь, что в директории проекта присутствуют необходимые веса:
- `cnn_toxicity.h5` — CNN модель для токсичности
- `tokenizer_tox.pkl` — Токенизатор для CNN
- `streamlit_model/config.json` — Конфигурация модели RuBERT

## 🏃 Использование

**Запустите API сервер**
```bash
uvicorn api:app --reload --host 0.0.0.0 --port 8000
```

**Запустите интерфейс (в новом терминале)**
```bash
streamlit run main.py
```

Откройте в браузере: `http://localhost:8501` (или другой указанный порт).
